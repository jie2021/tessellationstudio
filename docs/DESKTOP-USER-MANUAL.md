# Tessellation Studio 데스크톱 사용 매뉴얼

이 문서는 Windows Electron 앱과 데스크톱 웹 브라우저에서 Tessellation Studio를 사용하는 방법을 설명합니다.

## 1. 화면 구성

- **왼쪽 설정 패널**: 도형, 색상, 변 형태, 변형 종류, 초기화와 저장 기능을 제공합니다.
- **기본 도형 편집기**: 화면 중앙에서 타일의 변을 편집합니다.
- **배경 패턴**: 편집 결과가 반복 패턴으로 실시간 표시됩니다.
- **하단 도구 모음**: 가이드선, 확대/축소, 설명 모드를 제어합니다.

## 2. 빠른 시작

1. 왼쪽의 **기본 도형 선택**에서 삼각형, 사각형 또는 육각형을 선택합니다.
2. Primary와 Secondary 색상을 정합니다.
3. 변 형태에서 **직선** 또는 **곡선**을 선택합니다.
4. 사각형이나 육각형은 원하는 **변형 종류**를 선택합니다.
5. 중앙 편집기의 파란색 조절점을 마우스로 드래그합니다.
6. 배경에서 완성되는 반복 패턴을 확인합니다.
7. 왼쪽 패널 하단에서 PNG 또는 SVG로 저장합니다.

## 3. 마우스 편집

- 파란색 조절점을 클릭한 채 움직이면 변의 모양이 바뀝니다.
- 대응되는 변은 선택한 회전, 이동 또는 반사 규칙에 맞춰 자동으로 변경됩니다.
- 회색 꼭짓점은 기준점이며 직접 이동할 수 없습니다.
- **직선**에서는 조절점 위치가 꺾이는 지점이 됩니다.
- **곡선**에서는 조절점이 곡률을 제어합니다.
- 편집기 위의 **기본 도형 편집기** 버튼을 클릭하면 편집기를 접거나 펼칠 수 있습니다.

## 4. 도형별 변형

| 도형 | 선택 가능한 변형 | 용도 |
| --- | --- | --- |
| 삼각형 | 기본 삼각형 대칭 규칙 | 세 방향으로 이어지는 삼각 타일 제작 |
| 사각형 | 90도 회전 | 한 변의 변화가 회전된 변에 반영되는 패턴 |
| 사각형 | 평행 이동 | 마주 보는 변이 이어지는 패턴 |
| 사각형 | 미끄럼 반사 | 이동과 반사를 결합한 패턴 |
| 육각형 | 120도 회전 | 세 방향 회전 대칭 패턴 |
| 육각형 | 평행 이동 | 마주 보는 변이 이어지는 패턴 |
| 육각형 | 미끄럼 반사 | 이동과 반사를 결합한 패턴 |
| 육각형 | 자유형 | 세 쌍의 변을 더 자유롭게 편집하는 패턴 |

### 육각형 자유형에 점 추가

1. 육각형의 **자유형**을 선택합니다.
2. 파란 점선으로 표시된 편집 가능 변에서 점을 추가할 위치를 마우스 오른쪽 버튼으로 클릭합니다.
3. 추가된 파란색 조절점을 드래그합니다.

## 5. 색상 설정

- **Primary**: 주 타일과 편집기 윤곽에 사용하는 색상입니다.
- **Secondary**: 교차 배치되는 타일에 사용하는 색상입니다.
- 준비된 색상을 클릭하거나 색상 선택기를 열어 사용자 지정 색상을 선택할 수 있습니다.

## 6. 하단 도구 모음

- **격자 아이콘**: 중앙 편집기의 기준 가이드선을 표시하거나 숨깁니다.
- **Zoom 슬라이더**: 배경 반복 패턴을 0.5배에서 2배까지 확대하거나 축소합니다.
- **설명하기**: 현재 도형의 반복 원리를 단계별 애니메이션으로 보여 줍니다.
- 설명 중에는 **이전**, **다음**, **종료** 버튼을 사용합니다.

## 7. 초기화

왼쪽 패널의 **설정 초기화**를 클릭하면 현재 도형의 변 편집 결과가 기본 형태로 돌아갑니다. 색상, Zoom 등 다른 UI 설정 전체를 초기화하지는 않습니다.

도형을 새로 선택해도 해당 도형의 변 편집 상태는 기본값으로 시작합니다.

## 8. 파일 저장

### PNG 이미지

1. 왼쪽 패널 하단의 **패턴 이미지 저장**을 클릭합니다.
2. 현재 패턴 영역이 2배 해상도의 PNG로 생성됩니다.
3. 파일 이름은 `tessellation-도형이름.png` 형식입니다.

PNG는 문서, 프레젠테이션, 메신저 등 일반적인 이미지 사용에 적합합니다.

### SVG 벡터 이미지

1. **패턴 벡터 이미지 저장**을 클릭합니다.
2. 파일 이름은 `tessellation-도형이름.svg` 형식입니다.

SVG는 확대해도 선명하므로 인쇄, 편집 프로그램, 웹 디자인 작업에 적합합니다.

웹 브라우저에서는 기본 다운로드 폴더에 저장됩니다. Windows 앱에서는 시스템의 다운로드 처리 방식과 보안 설정에 따라 저장 알림이 표시될 수 있습니다.

## 9. 작업 요령

- 큰 형태를 먼저 만든 뒤 곡선 모드로 세부 모양을 조정합니다.
- 가이드선을 켜면 원래 도형의 변과 현재 변형 정도를 비교하기 쉽습니다.
- 작은 반복 무늬를 확인할 때는 Zoom을 낮추고, 변의 연결을 확인할 때는 Zoom을 높입니다.
- 편집 중간에 PNG나 SVG를 저장해 버전을 나누어 보관합니다.
- 설명 모드로 선택한 변형 방식이 어떻게 반복되는지 확인한 뒤 편집하면 대응 변을 이해하기 쉽습니다.

## 10. 문제 해결

### 조절점이 움직이지 않습니다

- 파란색 조절점인지 확인합니다. 자동 계산되는 대응 변의 점은 직접 움직일 수 없습니다.
- 설명 모드가 실행 중이면 **종료**를 클릭합니다.
- 편집기가 접혀 있다면 **기본 도형 편집기** 버튼으로 펼칩니다.

### 반복 패턴이 화면 밖으로 커졌습니다

하단 Zoom 슬라이더를 왼쪽으로 이동해 축소합니다.

### 저장 파일의 모양이 예상과 다릅니다

- 저장 전에 설명 모드를 종료합니다.
- 배경 패턴과 색상이 원하는 상태인지 확인합니다.
- 인쇄나 추가 편집에는 SVG, 일반 이미지 사용에는 PNG를 선택합니다.

### Windows 앱에 일반 프로그램 메뉴가 없습니다

Electron 버전은 작업 공간을 넓게 사용하도록 기본 Windows 메뉴를 숨깁니다. 앱의 모든 사용자 기능은 왼쪽 설정 패널과 하단 도구 모음에서 사용할 수 있습니다.
