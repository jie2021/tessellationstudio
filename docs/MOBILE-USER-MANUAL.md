# Tessellation Studio 모바일 사용 매뉴얼

이 문서는 Android 앱과 모바일 브라우저에서 Tessellation Studio로 반복 패턴을 만드는 방법을 설명합니다.

## 1. 화면 구성

- **상단 왼쪽 메뉴 버튼**: 도형, 색상, 변 형태, 변형 종류와 저장 기능을 엽니다.
- **상단 오른쪽 잠금 버튼**: 페이지 스크롤 잠금을 켜거나 끕니다.
- **기본 도형 편집기**: 조절점을 움직여 반복될 타일의 변을 편집합니다.
- **배경 패턴**: 편집 결과를 실시간으로 반복해 보여 줍니다.
- **하단 도구 모음**: 가이드선, 확대/축소, 설명 모드를 제어합니다.

## 2. 빠른 시작

1. 상단 왼쪽의 메뉴 버튼을 누릅니다.
2. **기본 도형 선택**에서 삼각형, 사각형 또는 육각형을 선택합니다.
3. **도형 색상**에서 Primary와 Secondary 색상을 선택합니다.
4. **변 형태**에서 직선 또는 곡선을 선택합니다.
5. 사각형이나 육각형은 **변형 종류**도 선택합니다.
6. 메뉴 바깥 영역이나 닫기 버튼을 눌러 메뉴를 닫습니다.
7. 상단 오른쪽 잠금 버튼을 눌러 스크롤을 잠급니다.
8. 편집기의 파란색 조절점을 손가락으로 끌어 패턴을 만듭니다.
9. 메뉴를 다시 열어 PNG 또는 SVG로 저장합니다.

## 3. 모바일 터치 조작

### 스크롤 잠금

- **열린 자물쇠**: 페이지를 위아래로 스크롤할 수 있습니다.
- **닫힌 자물쇠**: 페이지 이동을 막아 조절점을 안정적으로 드래그할 수 있습니다.
- 메뉴 설정을 바꿀 때는 잠금을 풀고, 도형을 편집할 때는 잠그는 방식을 권장합니다.

### 변 편집

- 파란색 조절점을 누른 채 움직이면 변의 모양이 바뀝니다.
- 대응되는 변은 선택한 변형 규칙에 따라 자동으로 계산됩니다.
- 회색 꼭짓점은 기준점이며 직접 움직일 수 없습니다.
- **직선**은 조절점을 꺾이는 점으로 사용하고, **곡선**은 부드러운 곡선 제어점으로 사용합니다.
- **기본 도형 편집기** 제목을 누르면 편집기를 접거나 펼칠 수 있습니다.

### 육각형 자유형

1. 육각형을 선택합니다.
2. 변형 종류에서 **자유형**을 선택합니다.
3. 편집 가능한 파란 점을 드래그합니다.
4. 점을 추가하려면 파란 점선으로 표시된 편집 가능 변을 길게 누릅니다.

기기의 길게 누르기 동작이 브라우저 메뉴로 처리되면 Android 앱 또는 다른 모바일 브라우저에서 다시 시도하세요.

## 4. 도형과 변형 종류

| 도형 | 선택 가능한 변형 |
| --- | --- |
| 삼각형 | 기본 삼각형 대칭 규칙 |
| 사각형 | 90도 회전, 평행 이동, 미끄럼 반사 |
| 육각형 | 120도 회전, 평행 이동, 미끄럼 반사, 자유형 |

도형이나 변형 종류를 바꾸면 편집 가능한 변과 자동으로 대응되는 변이 달라집니다.

## 5. 색상 설정

1. 메뉴에서 **도형 색상**을 찾습니다.
2. Primary는 주 패턴 색상, Secondary는 교차 타일 색상입니다.
3. 준비된 색상표를 누르거나 색상 선택기를 사용해 원하는 색을 고릅니다.

색상은 배경 패턴에 즉시 반영됩니다.

## 6. 하단 도구 모음

- **격자 아이콘**: 편집기의 기준 가이드선을 표시하거나 숨깁니다.
- **Zoom 슬라이더**: 배경 반복 패턴을 0.5배에서 2배까지 확대하거나 축소합니다.
- **설명하기**: 현재 도형과 변형 방식이 패턴을 만드는 과정을 단계별로 보여 줍니다.
- 설명 화면의 **이전**, **다음**, **종료** 버튼으로 단계를 조작합니다.

## 7. 초기화와 저장

### 변 편집 초기화

메뉴 하단의 **설정 초기화**를 누르면 현재 도형의 변 편집 결과가 기본 형태로 돌아갑니다. 선택한 색상이나 Zoom 값까지 모두 초기화하는 기능은 아닙니다.

### PNG 저장

1. 메뉴 하단의 **패턴 이미지 저장**을 누릅니다.
2. 현재 화면의 반복 패턴이 2배 해상도의 PNG 파일로 생성됩니다.
3. 파일 이름은 `tessellation-도형이름.png` 형식입니다.

### SVG 저장

1. **패턴 벡터 이미지 저장**을 누릅니다.
2. 확대해도 선명한 SVG 파일이 생성됩니다.
3. 파일 이름은 `tessellation-도형이름.svg` 형식입니다.

저장 위치와 다운로드 알림은 Android 버전 및 브라우저 설정에 따라 달라질 수 있습니다. 일반적으로 기기의 다운로드 목록이나 Downloads 폴더에서 확인할 수 있습니다.

## 8. 문제 해결

### 조절점을 움직일 때 화면도 함께 움직입니다

상단 오른쪽 자물쇠를 눌러 페이지 스크롤을 잠근 뒤 다시 드래그하세요.

### 편집기가 보이지 않습니다

- 화면 중앙의 **기본 도형 편집기** 제목을 눌러 펼칩니다.
- 설명 모드가 실행 중이면 **종료**를 누릅니다.

### 저장 버튼을 눌러도 파일이 보이지 않습니다

- Android의 파일 및 다운로드 알림을 확인합니다.
- 브라우저를 사용 중이면 다운로드 권한과 팝업 차단 설정을 확인합니다.
- SVG 저장이 제한될 경우 PNG 저장을 먼저 시도합니다.

### 패턴이 너무 크거나 작습니다

하단의 Zoom 슬라이더를 움직여 반복 패턴의 크기를 조정합니다.
